# Arquitectura

Esqueleto inicial inspirado en la estructura de capas de Askora Menus:

- `domain/` — entidades y reglas de negocio
- `features/` — casos de uso
- `infrastructure/` — adaptadores (logger, BD, APIs)
- `entrypoints/` — CLI y otros puntos de entrada
- `front/` — interfaz de usuario
- `config/` — settings y resolución de rutas
